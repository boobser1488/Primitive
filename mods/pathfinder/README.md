# pathfinder

`/walk`, `/mine`, `/where` — мозг Baritone, без пальцев.

## Команды

    /walk <x> <z>      спланировать путь и поехать
    /walk stop         остановиться
    /walk where        сколько осталось и куда
    /mine <block> [r]  найти ближайший и дойти до него
    /where             координаты

Радиус `/mine` по умолчанию 48, потолок 128. Дальность `/walk` — 200
блоков, дальше A* отказывается: за `MAX_RANGE` поиск стоит дороже, чем
дойти дважды.

## Чего мод не делает

**Не нажимает WASD.** Сервер не может. Клиент считает движение сам, и
единственный способ сдвинуть игрока отсюда — `teleport`, а он обнуляет
скорость клиента. Поэтому «идти» здесь — телепортироваться вдоль пути со
скоростью шага, по шагу за тик. Игрок на рельсах: смотреть по сторонам
можно, идти в другую сторону — нет.

Чтобы это было по-настоящему, нужен один протокол-месседж:
`ServerMessage::Nudge { dx, dy, dz }`, который клиент подмешивает в свой
ввод, как если бы игрок сам нажал клавиши. Это правка протокола, а не
мода, и она в чужих руках.

**Не копает по-настоящему.** `/mine` ставит `BLOCK_AIR` — ни дропа, ни
износа, ни анимации, ни добычи в смысле игры. Для «дойти до жилы и
посмотреть» хватает; для «добыть руду» — нет.

**Не прыгает выше блока.** Правило одно: шаг вверх на один блок. Прыжок
в два блока требует настоящего прыжка, а телепорт прыжком не бывает.
Путь вверх по лестнице из земли — есть; путь на дерево — нет.

**Не строит.** Мостов через овраг не будет.

## Сборка

    cargo build -p pathfinder --release
    copy target\release\pathfinder.dll mods\pathfinder\

Операторские права нужны: и телепорт, и `set_block` через границу мода
доступны не всем. В одиночном мире единственный игрок — оператор.

## Что проверить прежде, чем это соберётся

Сигнатуры хоста (`Context`, `ModApi`, `Event`, `blocks().is_solid`,
`world().set_block`) взяты по именам из README и CHANGELOG, а не из
`primitive_modapi/src/lib.rs`. Сверить первым делом. Три места, где
расхождение скорее всего:

- `Event::CommandRun` и форма `cmd.args` — возможно, это `Vec<String>`,
  возможно `&[String]`;
- `players().teleport` — возможно, возвращает `bool` и требует
  проверки, возможно тихо ничего не делает;
- `BLOCK_AIR` — константа хоста или её надо получать по имени
  (`blocks().id_by_name("air")`).
