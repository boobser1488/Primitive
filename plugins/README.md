# Плагины primitive

Плагин — это папка в этом каталоге с двумя файлами:

```
plugins/
  мой_плагин/
    plugin.toml     # метаданные
    main.rhai       # скрипт
```

Сервер сканирует каталог при запуске (путь настраивается через
`plugin_dir` в `settings.toml`). Порядок загрузки — алфавитный, чтобы он
не зависел от прихоти файловой системы: от него зависит, какой плагин
увидит событие первым.

Плагины не перезагружаются на лету — правки подхватываются при
перезапуске сервера.

## plugin.toml

```toml
name = "мой_плагин"          # обязательное
version = "1.0"              # необязательное
author = "кто-то"            # необязательное
description = "что делает"   # необязательное
script = "main.rhai"         # необязательное, это значение по умолчанию
enabled = true               # необязательное, по умолчанию true
```

## Скрипт

Язык — [Rhai](https://rhai.rs): небольшой встраиваемый язык, похожий на
JavaScript/Rust. Скрипт определяет любое подмножество хуков; ненужные
просто не пишутся — отсутствующий хук не ошибка.

```rhai
fn on_join(player, username) {
    broadcast(username + " зашёл на сервер");
    tell(player, "Привет!");
}
```

### Хуки

| функция | когда вызывается | что значит `return false` |
|---|---|---|
| `on_load()` | старт сервера | — |
| `on_join(player, username)` | игрок подключился | — |
| `on_leave(player, username)` | игрок отключился | — |
| `on_chat(player, text)` | сообщение в чат | отменить сообщение |
| `on_block_place(player, x, y, z, block)` | **перед** постановкой блока | отменить постановку |
| `on_block_break(player, x, y, z)` | **перед** ломанием блока | отменить ломание |
| `on_command(player, command, args)` | неизвестная `/команда` | «я обработал её» |
| `on_tick(tick)` | раз в секунду | — |

Хуки блоков вызываются **до** изменения мира, а не после. Плагину защиты
нужно успеть сказать «нет», а не откатывать уже случившееся. Если хотя бы
один плагин вернул `false`, действие отменяется — поэтому несколько
защитных плагинов складываются между собой без договорённостей.

`on_tick` вызывается раз в секунду, а не каждый такт: скрипт, который
запускается 20 раз в секунду, — это ловушка для автора плагина, и ничему
здесь не нужна точность такта.

### Что можно вызывать

Действия (применяются после того, как хук вернул управление):

| функция | эффект |
|---|---|
| `broadcast(text)` | сообщение всем |
| `tell(player, text)` | сообщение одному игроку |
| `log(text)` | строка в лог сервера с именем плагина |
| `set_block(x, y, z, block)` | поставить блок (неизвестный id отбрасывается) |
| `kick(player, reason)` | отключить игрока |
| `set_time(t)` | время суток, 0.0–1.0 |
| `teleport(player, x, y, z)` | переместить игрока |
| `fill(x0, y0, z0, x1, y1, z1, block)` | залить блоками параллелепипед, вернуть сколько поставлено |
| `spawn_falling_block(x, y, z, block)` | поставить блок и уронить его |

Запросы (читают снимок мира, собранный до вызова):

| функция | возвращает |
|---|---|
| `time_of_day()` | 0.0–1.0 |
| `player_count()` | число игроков онлайн |
| `player_names()` | массив имён |
| `player_position(player)` | `[x, y, z]` или пустой массив |
| `get_block(x, y, z)` | id блока, либо -1 |
| `block_name(id)` | имя блока строкой |
| `block_id(name)` | id блока по имени, либо -1 |
| `player_id(name)` | id игрока по имени (регистр не важен), либо -1 |
| `world_seed()` | сид мира |
| `tick()` | номер текущего такта |
| `is_solid(id)` | сквозь блок нельзя пройти |
| `is_air(id)` | это воздух |

Про `-1`: и `block_id`, и `player_id` возвращают именно −1, а не 0. Ноль
не является допустимым id игрока, но скрипт, забывший проверить,
молча обратился бы к игроку 0 вместо «никого».

Про `fill`: цикл из `set_block` в скрипте — очевидная альтернатива и
непригодная, потому что лимит операций движка остановит скрипт задолго
до того, как он выложит стену. Одним вызовом работу ограничивает **хост**,
а там ей и место: за раз пишется не больше 4096 блоков, по вертикали
всё обрезается границами мира, и функция возвращает, сколько блоков
реально поставлено — чтобы скрипт заметил обрезку, а не считал, что
стена уже стоит.

Постоянное состояние: переменная `store` — таблица строк, переживающая
вызовы хуков.

```rhai
fn on_tick(tick) {
    let count = 0;
    if store.contains("count") { count = parse_int(store.count); }
    count += 1;
    store.count = "" + count;
}
```

## Границы, о которых стоит знать заранее

- **Мир виден снимком.** Хук вызывается, когда сервер уже может держать
  блокировки мира и реестра игроков, поэтому обращение скрипта обратно в
  живое состояние заблокировало бы тик-луп. По той же причине действия
  возвращаются как данные и применяются после завершения скрипта.
- **`get_block` отдаёт только ячейки, относящиеся к событию** (например,
  ту, которую ломают). На остальные вернётся -1.
- **Встроенные команды приоритетнее.** `/players` — синоним `/list`, до
  плагина он не дойдёт; подменить `/stop` нельзя. Выбирайте имя, которого
  у сервера нет.
- **Неизвестный id блока отбрасывается** на границе, а не доезжает до
  мира.
- **Лимит операций.** Зациклившийся скрипт прерывается, а не вешает
  сервер. Плагин, падающий 10 раз подряд, отключается до перезапуска.
- **Песочница.** Файлы, сеть и процессы не зарегистрированы — плагин не
  дотянется до того, чего сервер ему не дал.
- **Функции Rhai изолированы.** Они не видят объявленные в скрипте
  `const` и глобальные переменные. Общие значения оформляйте функциями:
  `fn spawn_radius() { 8 }`.
- **Осторожно с зарезервированными словами.** Например, `protected` —
  ключевое слово Rhai, и функция с таким именем не скомпилируется. Ошибка
  будет видна в логе при запуске.

## Примеры в комплекте

| плагин | что показывает |
|---|---|
| `welcome` | реакция на события, чтение снимка мира, своя команда `/online` |
| `bedrock_guard` | отмена действий: защита дна мира и радиуса вокруг спавна |
| `daylight` | состояние между вызовами через `store` (выключен по умолчанию) |

Чтобы попробовать `daylight`, поставьте `enabled = true` в его
`plugin.toml` и перезапустите сервер.
